# Hiring Day AAC · Fase 2

1. **Qué es:** un único `index.html` estático (sin backend, sin CDNs, funciona offline). Los datos se quedan en el `localStorage` del navegador del portátil.
2. **Antes de cada candidato:** el entrevistador abre la URL de Pages (o el `index.html` local), pone el nombre del candidato y su PIN → "Empezar".
3. **Durante:** el candidato tiene el análisis a la izquierda y la plantilla a la derecha. Si se recarga la página, la sesión se recupera. El tiempo lo controla el entrevistador.
4. **Al terminar:** "Entrevistador" (PIN) → descargar Markdown y PDF (`nombre_candidato_fecha`) y guardarlos en la carpeta compartida del Hiring Day.
5. **Siempre** pulsar "Reiniciar para el siguiente candidato" (PIN) antes de entregar el portátil: borra todo lo guardado en ese navegador.
