# Hiring Day AAC · Fase 2

1. **Qué es:** un único `index.html` estático (sin backend, sin CDNs, funciona offline). Los datos se quedan en el `localStorage` del navegador del portátil.
2. **Antes de cada candidato:** el entrevistador abre la URL de Pages (o el `index.html` local), pone nombre, turno (T1–T4) y su PIN → "Empezar".
3. **Durante:** temporizador 15' lectura y preguntas · 20' escritura · 10' explicación (aviso a 5'). "Entrevistador" (PIN) permite pausar o saltar de bloque. Si se recarga la página, la sesión se recupera.
4. **Al terminar:** "Entrevistador" → "Cerrar y descargar entrega" → descargar Markdown y PDF (`nombre_candidato_fecha`) y guardarlos en la carpeta compartida del Hiring Day.
5. **Siempre** pulsar "Reiniciar para el siguiente candidato" (PIN) antes de entregar el portátil: borra todo lo guardado en ese navegador.
